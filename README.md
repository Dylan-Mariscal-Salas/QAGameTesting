# Bug Report: Trader Menu UI Persistence  
**Game:** Escape from Tarkov | **Request ID:** #19474747  

## Description  
If you press escape after a text box appears with a warning saying that you can't sell a box to a trader containing some items, this box will stay visible no matter what unless you go to the trader section and select sell an hover the mouse on another item.

## Reproduction Steps  
- Step 1: Select traders on main menu
- Step 2: Go to sell tab
- Step 3: Hover mouse to any box containing items inside
- Step 4: Press escape button
- Step 5: The text box is still visible

## Expected vs Actual Behavior  
- **Expected:** Text box should is still visible
